# 🍊 Swiggy Sales Analysis — Excel Dashboard

<p align="center">
  <b>Turning food-order data into clear business insights.</b>
</p>

An interactive sales analysis project built in Microsoft Excel to explore Swiggy order data through KPIs, PivotTables, charts, and dashboard filters.

## 📌 Project Overview

This project analyzes Swiggy food-order data to understand sales performance, customer ratings, food categories, and regional trends. The Excel workbook includes an analysis sheet and an interactive dashboard that brings key metrics together in one place.

## 🎯 Project Objectives

- Analyze overall sales and order performance.
- Explore monthly and daily sales trends.
- Compare sales across food categories and states.
- Identify top-performing cities by sales.
- Examine average customer ratings and rating counts.
- Build an interactive dashboard for easier data exploration.

## 🛠️ Tools & Features

**Tool:** Microsoft Excel

- PivotTables and summarized metrics
- Interactive slicers for month, restaurant, and category
- KPI cards for sales, ratings, orders, and average order value
- Line charts, bar charts, and a doughnut chart
- State-wise sales map
- Monthly, daily, and weekly trend analysis

## 📊 Dashboard Highlights

| Metric / View | Purpose |
|---|---|
| Total Sales | Understand overall sales value |
| Average Rating | Review customer rating performance |
| Average Order Value | Explore average sales value per order |
| Total Orders | Understand order volume |
| Monthly Sales Trend | Compare sales across months |
| Daily & Weekly Trends | Explore sales patterns over time |
| Food Type Analysis | Compare sales across food types |
| State & City Analysis | Explore geographic sales performance |

## 🔎 Interactive Analysis

The dashboard includes slicers for:

- Month
- Restaurant Name
- Category

These filters allow users to explore different parts of the dataset and compare sales performance across selected groups.

## ▶️ How to Use

1. Download or clone this repository.
2. Open `Swiggy Analysis.xlsx` in Microsoft Excel.
3. Navigate to the **Dashboard** sheet to view the visual summary.
4. Use the slicers to filter by month, restaurant, or category.
5. Explore the **Analysis** and **Total Sales** sheets for additional details.

> **Note:** For the best experience with interactive slicers and Excel charts, open the workbook in the desktop version of Microsoft Excel.

## 💡 Key Takeaway

This project demonstrates how Microsoft Excel can be used to transform raw food-order data into an interactive sales dashboard. It provided practical experience with data summarization, KPI reporting, PivotTables, charts, and business-focused data analysis.
